# Proyecto de Prueba Git

Este es un repositorio de prueba para aprender a documentar proyectos y gestionar el control de versiones usando Git y GitHub.

## Instalacion de como clonar

Para clonar t probar este repositorio en tu computadora, ejecuta en la terminal:

```bash
git clone https://github.com/tu-usuario/prueba4.git

cd prueba4
```

## Usage

```python
#ejemplo de codigo en phyton

def saludar(nombre):
   return "Hola, {nombre}, bienvenido a Git"

   mensaje = saludar("Estudiante")
   print(mensaje)
```
